# SOC Prep

Web ôn tập An ninh mạng, Quản trị mạng (CCNA cốt lõi), tiếng Anh chuyên ngành và hướng dẫn lab – chuẩn bị phỏng vấn SOC Tier 1.

- HTML/CSS/JS thuần, không cần build. Mở `index.html` là chạy.
- Nội dung nằm trong `data/*.js` (định dạng: `data/SCHEMA.md`).
- Tiến độ lưu trên trình duyệt (localStorage).
